# Dot product

- Dot Product is a **Similarity Score**
- `A · B = |A| |B| cos(theta)` is the dot product of two vectors A and B.
- Matrix multiplication is a collection of dot products.


| Angle | cos(θ) |      Dot Product |
| ----: | -----: | ---------------: |
|    0° |      1 | Maximum positive |
|   90° |      0 |             Zero |
|  180° |     -1 | Maximum negative |

## Dot Product vs Matrix Multiplication

| Dot Product           | Matrix Multiplication        |
| --------------------- | ---------------------------- |
| Two vectors           | Two matrices                 |
| Produces one scalar   | Produces a matrix            |
| Measures similarity   | Collection of dot products   |
| Used inside attention | Used throughout Transformers |
